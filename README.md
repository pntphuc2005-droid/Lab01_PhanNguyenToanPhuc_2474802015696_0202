# vlu-qe-pipeline-master

Văn Lang University - Software Testing - Lab 01

## Chặng 2
Thiết kế mã nguồn và hai tập kịch bản kiểm thử:
- Smoke Test: kiểm tra đăng nhập đúng `admin/123`.
- Regression Test: kiểm tra đăng nhập đúng và các trường hợp ngoại lệ.

## Chạy kiểm thử

Cài dependencies:

    npm install

Chạy Smoke Test:

    npm run test:smoke

Chạy Regression Test:

    npm run test:regression
